# Universal Learning GPS

Modern, responsive educational platform built with **Next.js + Tailwind CSS**.

## Features Implemented

- AI-style roadmap generator with timelines
- Skill gap analysis and curated resources
- Personalized dashboard with progress and achievement badges
- AI career mentor chat (guided response engine)
- Full site pages:
  - Home
  - Features
  - How It Works
  - Dashboard
  - Roadmap Generator
  - Pricing
  - About
  - Contact
  - Login / Sign Up
- Responsive navigation and modern UI theme
- SEO-ready metadata and scalable app-router structure

## Tech Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Lucide React icons

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build & Lint

```bash
npm run lint
npm run build
```
