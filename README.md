# Universal Learning GPS 🧭

**Navigate Your Future with AI.**

Universal Learning GPS is a modern, AI-powered educational platform that creates personalized learning roadmaps and guides users toward their academic and career goals.

## 🌟 Features

- **AI-Powered Learning Roadmaps** — Generate step-by-step learning paths based on your career goals
- **Skill Gap Analysis** — Identify missing skills and get targeted recommendations
- **AI Career Mentor** — 24/7 chatbot for career guidance, study plans, and interview tips
- **Curated Resources** — Courses from Coursera, edX, Udemy, YouTube and more
- **Progress Tracking** — Visual dashboards, progress bars, and achievement badges
- **Certifications** — Downloadable certificates and learning reports
- **User Authentication** — Sign up/login with Google and Email

## 🖥️ Pages

- **Home** — Hero section with stats and testimonials
- **Features** — Detailed feature showcase
- **How It Works** — Step-by-step process guide
- **Roadmap Generator** — Interactive AI-powered roadmap generator
- **Dashboard** — Personalized user dashboard with AI mentor chat
- **Pricing** — Free and premium subscription plans
- **About Us** — Mission, team, and milestones
- **Contact** — Support form and social links
- **Login / Sign Up** — Authentication pages

## 🎨 Design

- **Color Palette:** Dark Blue (#1A1A2E), White (#FFFFFF), Orange (#FF7A00)
- **Typography:** Poppins (Google Fonts)
- **Style:** Modern, futuristic, minimalistic with smooth animations
- **Responsive:** Fully optimized for desktop, tablet, and mobile

## ⚙️ Tech Stack

- **Frontend:** Next.js 16 (App Router) with TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Deployment:** Vercel-ready

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
